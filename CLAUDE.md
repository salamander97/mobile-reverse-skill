# CLAUDE.md

Use this repository as a portable skill source for authorized mobile reverse
engineering. Start with `README_AI.md`, then route through
`skills/scripts/master-route.sh` or `master-route.ps1` and initialize the
caller project's case before any target action.

`skills/config/routing.json` is canonical. Read `skills/tool-index.md` for
machine-specific availability. Dynamic instrumentation, traffic replay, and
device interaction require an explicit authorized scope.
